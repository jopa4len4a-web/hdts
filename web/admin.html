Безопасность и хранение

Рекомендуется: постоянный том для SQLite, резервные копии, HTTPS, ограничение частоты запросов, актуальные правила обработки данных и ротация секретов при подозрении на утечку.

Не вставляй секреты Platega в клиентский JavaScript. Сохраняй их только на сервере. Никогда не публикуй BOT_TOKEN.
